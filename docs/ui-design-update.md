# View 작업 정리: 홈 화면 새 디자인·흰 바탕·포커스 테두리·장바구니 버튼 수정

작성: (이름) · 2026-11-22 · 브랜치 `feat/ui-redesign`

홈 화면 위쪽을 쇼핑몰처럼 **진보라 띠 + 넓은 검색창 + 카테고리 탭**으로 바꾸고, 섹션의 회색 버튼을 밑줄 글자 링크로 정리했습니다. 홈·룩북·옷 입혀보기 바탕을 흰색으로 바꿨고, 상품 화면은 내려도 카테고리 탭이 따라옵니다. 상단 메뉴에 테두리가 저절로 생기던 문제와 장바구니에서 버튼이 잘리던 문제도 고쳤습니다.

> **강준서 님**: 담당 파일(`MainFrame`, `ProductListPanel`)을 고쳤고, 흑백 테마 규칙의 예외를 하나 만들었습니다. 합치기 전에 [6. 다른 담당 파일 변경](#6-다른-담당-파일-변경)과 [7. 팀과 상의할 점](#7-팀과-상의할-점)을 꼭 봐 주세요.

---

## 1. 바로 보기

1. IDE에서 `com.sadamda.App`의 `main`을 실행합니다.
2. 아래 순서로 눌러 보면 이번 변경을 대부분 볼 수 있습니다.

| 해 볼 것 | 보이는 결과 |
|---|---|
| 앱을 켜고 홈 보기 | 맨 위에 진보라 띠, 그 안에 흰 검색창과 카테고리 탭(전체·상의·…·스카프) |
| 홈 카테고리 탭에 마우스 올리기 | 흰 글자에 흰 밑줄 |
| 홈을 아래로 내리기 | 맨 위에 같은 진보라 카테고리 탭 줄이 고정되어 나타남 |
| 홈 "이번 시즌 유행 아이템"의 [유행 아이템 모두 보기 (28개)] | 28개 모두 보임, 글자가 [줄여 보기]로 바뀜 |
| [상품] 화면에서 목록 내리기 | 검색창은 위로 사라지고 카테고리 탭만 맨 위에 붙어 따라옴 |
| 로그인하기 | 상단 메뉴 [홈] 등에 네모 테두리가 생기지 않음 |
| 장바구니 상품 카드 보기 | [−] 수량 [+] 아래에 [옵션 변경] 버튼이 온전히 보임 |

## 2. 홈 화면 (`HomePanel`, `CategoryBar`)

### 2.1 맨 위 진보라 띠

- 예전의 인사말 카드와 "카테고리로 찾기" 섹션을 없애고, **창 폭 가득한 진보라 띠**(`#6A4BD8`) 하나로 합쳤습니다.
- 띠 안에는 **흰 사각 검색창**과 그 아래 **카테고리 탭**만 있습니다. 인사말("어서 오세요, 사담다입니다." 등)은 뺐습니다.
- 검색창은 오른쪽 돋보기 버튼을 누르거나 Enter로 검색합니다(UC-05). 포커스가 있으면 진한 테두리가 생깁니다.
- 띠를 창 끝까지 붙이려고 `HomePanel`의 바깥 여백(`ScreenPanel`의 24px)을 없앴습니다. 띠 아래 섹션들은 따로 좌우 32px 여백을 둡니다.
- 글자 대비: 띠 위 흰 글씨 5.8:1, 연보라 글씨(`#EEEAFF`) 4.9:1 (NFR-01 4.5:1 이상).

### 2.2 카테고리 탭 (`CategoryBar`)

- 회색 알약 버튼 대신 **글자만 있는 탭**입니다. 상품 화면의 탭과 같은 크기(20px)·간격이고, 글자는 항상 굵게 씁니다.
- 맨 앞에 [전체] 탭이 있어서 예전의 [전체 상품 보기] 버튼을 대신합니다.
- 상품 수 숫자("상의 35")는 글자에서 빼고 툴팁·스크린리더 이름으로만 알립니다.
- 탭 색을 바꾸는 `setColors(평소 글씨, 고른 글씨, 밑줄)`을 추가했습니다. 홈에서는 연보라 → 흰 글씨·흰 밑줄을 씁니다. 지정하지 않으면 흰 바탕용 기본색(회색 → 검정)입니다.
- 홈으로 돌아왔을 때 탭이 눌린 채로 남지 않게 `clearSelection()`을 추가했습니다.
- `CategoryBar`는 홈에서만 쓰므로 다른 화면에는 영향이 없습니다.

### 2.3 섹션 정리

모든 섹션의 오른쪽 회색 버튼을 없애고, 필요한 것만 **안내 문구 바로 아래 밑줄 글자 링크**로 바꿨습니다. 마우스로 눌러도 링크에 테두리가 생기지 않습니다(Tab 키로 오면 보임).

| 섹션 | 바뀐 점 |
|---|---|
| 나에게 어울리는 상품 (비회원) | 안내 문구 삭제, [로그인하기] → 링크 |
| 나에게 어울리는 상품 (체형 정보 없음, 3a) | [체형 정보 입력하기] → 링크 |
| 이번 시즌 유행 아이템 | 안내 문구 삭제, [유행 아이템 모두 보기 (N개)] ↔ [줄여 보기] → 링크 |
| 추천 코디 | [코디 모두 보기] 삭제 (상단 메뉴 [룩북]으로 이동 가능) |
| 옷 입혀보기 | [옷 입혀보기] → 링크 |
| 새로 들어온 상품 | [상품 더 보기] 삭제 (띠의 [전체] 탭·상단 메뉴 [상품]으로 이동 가능) |

## 3. 상품 화면: 카테고리 탭 따라오기 (`ProductListPanel`)

- 예전에는 검색창과 카테고리 탭이 한 덩어리로 위에 고정되어 있었습니다.
- 이제 목록을 내리면 **검색창은 함께 올라가 사라지고, 카테고리 탭이 맨 위에 닿으면 붙어서 따라옵니다.**
- 방법: 머리말을 목록 위에 겹쳐 두고, 스크롤한 만큼 위로 밀어 올리다가 탭이 맨 위에 닿으면 멈춥니다(`withStickyTabs`). 탭을 따로 하나 더 만들지 않습니다.
- 목록 맨 위에는 머리말 높이만큼 여백을 둡니다(`Body.setTopSpace`). 카테고리를 바꾸면 기존 코드대로 목록이 맨 위로 가서 검색창이 다시 보입니다.

## 4. 바탕색을 흰색으로

공통 색 `Theme.PAGE`(연한 회색 `#F2F2F2`)는 **그대로 두고**, 아래 화면에서만 흰색(`CARD`)을 씁니다. 장바구니·주문 내역 등 다른 화면은 여전히 회색입니다.

| 화면 | 파일 |
|---|---|
| 홈 | `HomePanel` |
| 룩북 (목록·코디 보기) | `LookbookPanel` |
| 옷 입혀보기 | `TryOnPanel` |

룩북 화면에서는 [새 코디 올리기] 버튼도 없앴습니다. 새 코디는 **관리자 화면 → 룩북 탭의 [새 코디 등록]** 에서 올립니다. 코디 보기의 관리자용 [수정]·[삭제]는 그대로입니다.

## 5. 버그 수정

### 5.1 상단 메뉴에 네모 테두리가 저절로 생김 (`MainFrame`)

- **증상**: 로그인 후나 화면을 옮긴 뒤 [홈] 메뉴나 사담다 로고에 네모 테두리가 남아 있었습니다.
- **원인**: 화면이 바뀌어 포커스가 있던 칸(예: 로그인 화면의 비밀번호 칸)이 사라지면, Java가 포커스를 창 맨 앞 버튼(로고·[홈])으로 저절로 옮깁니다. 테두리는 포커스가 있을 때 그려지므로 클릭하지 않아도 생겼습니다.
- **수정**: 상단 메뉴줄의 모든 버튼(로고, 메뉴, [글씨 크기])이 **포커스를 받지 않게** 했습니다(`setFocusable(false)`). 메뉴의 포커스 테두리를 그리던 코드도 지웠습니다. 마우스 동작은 그대로입니다.

### 5.2 장바구니 [옵션 변경]·[+] 버튼이 잘림 (`CartPanel`)

- **증상**: 수량 아래에 흰 줄 같은 것이 보이고 [옵션 변경]을 누를 수 없었습니다. 고친 직후에는 [+]가 사라졌습니다.
- **원인**: 상품 이름이 길어 카드가 다 들어가지 못하면 `GridBagLayout`은 각 칸을 "최소 크기"로 놓습니다. 그런데 수량 줄(`FlowLayout`)의 최소 폭이 실제 필요한 폭보다 좁아서, 줄 맨 끝 버튼이 다음 줄로 밀려 잘렸습니다. 흰 줄은 잘린 [옵션 변경]의 윗부분이었습니다.
- **수정**:
  - [옵션 변경]을 수량 줄 아래 따로 두었습니다.
  - 수량 줄의 최소 크기를 필요한 크기와 같게 해서 [−] 수량 [+]가 항상 한 줄에 보입니다.

## 7. 팀과 상의할 점

1. **흑백 테마 규칙의 예외**: `Theme` 주석에는 "흑백 톤, 색은 오류(빨강)에만 쓴다"고 되어 있습니다. 홈 화면 띠에만 진보라(`#6A4BD8`)를 썼습니다. 다른 화면에도 쓸지, 홈에서만 쓸지 정해야 합니다. 색은 `HomePanel`의 `BAND` 상수 하나로 바꿀 수 있습니다.
2. **상단 메뉴 키보드 사용**: 5.1의 수정으로 Tab 키로는 상단 메뉴에 갈 수 없습니다. 키보드만으로 메뉴를 쓸 수 있어야 한다는 요구사항이 있으면 다른 방법(예: 단축키)이 필요합니다.
3. **홈에서 다른 화면으로 가는 길**: [코디 모두 보기]·[상품 더 보기]를 없앴으므로, 룩북·전체 상품은 상단 메뉴나 띠의 [전체] 탭으로 갑니다.

## 8. 시도했다가 되돌린 것

최종 코드에는 없습니다. 같은 시도를 반복하지 않도록 적어 둡니다.

- 홈 검색 카드의 파스텔 그라데이션·반짝이 장식 → 진보라 띠로 바뀜
- 홈 띠 색: 검정 → 연분홍 → 연보라 → **진보라(최종)**
- 홈 띠의 "사담다" 글자 → 삭제
- 사담다 로고를 두꺼운 고딕으로 변경 → 원래 명조로 되돌림
- 룩북 화면 위쪽에 진보라 띠 → 원래대로 되돌림 (흰 바탕만 유지)
