# 사담다 차별 기능: 가족에게 물어보기

작성: 2026-11-19 · 브랜치 `feat/ask-family`

## 왜 만들었나

40~60대 회원은 옷을 고른 뒤 **딸·아들에게 사진을 보내 "이거 어때?" 하고 묻고**, 결제도 자녀가 대신 해 주는 일이 많습니다. 보통 쇼핑몰에서는 이 과정이 카톡·전화로 바깥에서 일어나서 구매가 끊깁니다. 사담다는 **묻고, 답하고, 대신 결제하는 것까지 서비스 안에서** 하게 했습니다.

## 화면 흐름

| 누가 | 어디서 | 무엇을 |
|------|--------|--------|
| 엄마 | 상품 상세 (사이즈·색상·수량을 고른 뒤) | **[가족에게 물어보기]** → 가족 이메일 + 하고 싶은 말 → "김지은님에게 물어봤어요" 알림 |
| 엄마 | 장바구니 (주문 정보 카드 아래) | **[가족에게 물어보기]** → 장바구니 상품 전체를 한 번에 물어봄 |
| 딸 | 로그인 직후 | "가족 쇼핑에 새 소식이 n개 있어요 · 확인하기" 알림, 상단 **가족 쇼핑 n** |
| 딸 | 가족 쇼핑 > 가족이 물어본 옷 | 엄마의 한마디, 상품(사진 누르면 상세), 합계 → 한마디 남기기 + **[좋아요] / [다른 걸 추천해요]**, 또는 **[대신 결제해 드리기]** (결제 수단 고르기) |
| 엄마 | 상단 **가족 쇼핑 n** | 내가 물어본 옷: "기다리는 중" / "김지은님의 답: ♥ 좋아요 “…”" + **[장바구니에 담기]** / "김지은님이 대신 결제해 줬어요!" |

- 대신 결제는 **선물하기(UC-12)** 를 그대로 씁니다. 받는 분 = 묻는 사람(이름·연락처·기본 배송지), 선물 메시지 = 딸의 한마디. 주문은 딸의 주문 내역에 "선물 주문"으로 남습니다.
- 새 소식 수 = (나에게 온, 아직 답하지 않은 요청) + (내가 물어본 것 중 새로 답이 온 것). 엄마가 가족 쇼핑 화면을 열면 새 답 표시가 지워집니다.
- 실패는 화면에 그대로 보여 줍니다: 가입하지 않은 이메일, 나 자신에게 묻기, 이미 대신 결제한 요청, 묻는 사람의 기본 배송지 없음, 품절.

## 코드

| 계층 | 파일 | 역할 |
|------|------|------|
| Model | `model/family/AskRequest` | 요청 한 건: 묻는 사람·받는 사람·상품 줄(`OrderLine`)·한마디·상태(`WAITING/LIKED/DISLIKED/PAID`)·답·대신 결제한 주문 번호 |
| Model | `model/family/AskService` | 묻기, 답하기, 대신 결제 표시(두 번 결제 방지), 새 소식 수, 마지막으로 물어본 가족 이메일 |
| Model | `MemberService.findByEmailOrNull` | 이메일로 가족 회원 찾기 (추가) |
| Controller | `controller/FamilyController` (`context.family`) | `ask`, `askCart`, `myAsks`, `asksToMe`, `respond`, `payFor`, `totalOf`, `newsCount`, `lastFamilyEmail`, `nameOf` |
| Controller | `OrderController.prepareLinesTotal` | 대신 결제 전 금액(상품 + 배송비) 계산 (추가) |
| View | `view/family/FamilyPanel` | 가족 쇼핑 화면 |
| View | `view/family/AskFamilyDialog` | 물어보기 창 (상세·장바구니에서 같이 씀) |
| View | `MainFrame.refreshFamilyBadge` | 상단 "가족 쇼핑 n", 로그인 때 새 소식 알림 |

## 시연 순서 (약 2분)

1. `demo@sadamda.com` / `demo1234` 로그인 → 상품 상세에서 사이즈·색상 고르기 → **[가족에게 물어보기]** → `daughter@sadamda.com`, "다음 달 결혼식에 입으려는데 어때?"
2. 로그아웃 → `daughter@sadamda.com` / `demo1234` 로그인 → "새 소식" 알림 → **[가족 쇼핑]** → 한마디 "색이 정말 잘 어울려요!" + **[좋아요]**, 다른 요청은 **[대신 결제해 드리기]**
3. 로그아웃 → 다시 `demo` 로그인 → "가족 쇼핑 2" → 딸의 답과 "대신 결제해 줬어요!" 확인 → **[장바구니에 담기]**
