# View 작업 안내: 상품 목록·검색·상세 화면

작성: 강준서 (View 담당) · 2026-11-14 · 브랜치 `feat/product-view`
수정: 2026-11-17 · 브랜치 `feat/order-view` (실제 데이터 연결, 카테고리 10개, 상세 화면 수량·색상·AI 입어보기. 자세한 내용은 [docs/ui-data-update.md](ui-data-update.md))

상품 목록(UC-04 카테고리별 상품 조회)과 검색(UC-05 상품 검색 및 필터) 화면을 만들었습니다. 큰 카테고리 버튼을 누르면 해당 상품을 큰 사진 카드로 보여 주고, [더 보기]로 이어서 볼 수 있습니다. 검색하면 모든 카테고리에서 찾고, 검색 결과는 필터와 정렬로 좁힐 수 있습니다. 상품 카드를 누르면 상품 상세(UC-06) 화면에서 사진을 크게 보고 사이즈·색상·수량을 골라 담거나 구매할 수 있습니다. 상품은 **실제 데이터(`context.product`, 데모 데이터 370개)**로 동작합니다 (4번 참고).

공통 디자인(`Theme`)과 화면 이동 규칙은 [docs/auth-view.md](auth-view.md)를 참고해 주세요.

---

## 1. 바로 보기

1. IDE에서 `com.sadamda.App`의 `main`을 실행합니다.
2. 상단 메뉴 **[상품]**을 누릅니다. 로그인하지 않아도 볼 수 있습니다.

> 상품 사진은 쇼핑몰 이미지 주소에서 받아 옵니다. **인터넷이 연결되어 있어야** 사진이 보입니다. 연결이 없으면 사진 칸에 "사진 없음"이 나오고, 나머지는 정상으로 동작합니다.

화면 구성 (위에서 아래로):

| 영역 | 내용 |
|---|---|
| 머리말 | 왼쪽에 "상품" 제목, 오른쪽에 **검색창과 [검색]** 버튼. 그 아래 카테고리 버튼 **[상의] [하의] [원피스] [아우터] [모자] [신발] [양말] [주얼리] [가방] [스카프]**. 고른 버튼은 검정, 나머지는 연한 회색. 목록을 내려도 그대로 보임 |
| 검색 결과 안내 (검색했을 때만) | "'가디건' 검색 결과 7개"와 [검색 지우기], 필터 두 줄과 정렬 버튼 한 줄 |
| 상품 카드 | 연한 회색 칸에 사진, 그 아래 상품명(두 줄까지), 굵은 가격 |
| 맨 아래 | **[더 보기]** 버튼 (더 볼 상품이 있을 때만) |

## 3. 화면이 동작하는 방식

### 카테고리 (UC-04 1~2단계)

- 처음 열면 **상의**를 보여 줍니다. 다른 화면에 다녀와도 보던 카테고리와 스크롤 위치를 유지합니다.
- 카테고리 버튼을 누르면 그 카테고리의 첫 페이지를 보여 주고 맨 위로 올라갑니다.

### 상품 카드

- 사진은 칸에 꽉 차게 넣고 넘치는 부분은 잘라냅니다. 칸 비율은 쇼핑몰 사진에 맞춘 3:4입니다.
- 상품명은 두 줄까지 보이고, 넘치면 "…"로 줄입니다. 마우스를 올리면 전체 이름이 보입니다.
- 상품명이 한 줄이어도 두 줄 자리를 잡아서, 같은 줄의 가격 위치가 가지런합니다.
- **카드 전체가 버튼**입니다. 마우스로 누르거나, Tab으로 이동해 Space를 누르면 그 상품의 상세 화면(UC-06)이 열립니다. 키보드로 오면 사진 둘레에 검정 테두리가 보입니다.

### 한 줄에 놓이는 카드 수

카드 폭은 항상 **240px 이상**입니다 (NFR-02 목록 이미지 너비). 창 폭에 맞춰 한 줄의 카드 수가 자동으로 바뀝니다.

| 상황 | 한 줄 카드 수 |
|---|---|
| 창 폭 1280px, 글씨 보통 | 4개 |
| 창 폭 1280px, 글씨 아주 크게 | 3개 (글씨가 커지면 최소 폭도 커짐) |
| 창 폭 800px, 글씨 보통 | 2개 |

### [더 보기] (UC-04 3단계)

- 한 번에 **8개**씩 보여 주고, [더 보기]를 누르면 다음 8개를 아래에 덧붙입니다 (`page`가 0부터 1씩 늘어남).
- 받아 온 상품이 8개보다 적으면 마지막 페이지로 보고 버튼을 감춥니다.
- 누른 뒤에는 키보드 포커스가 **새로 붙은 첫 상품**으로 옮겨 갑니다.

### 상품이 없을 때 (UC-04 2a)

"**준비 중인 상품입니다**"와 "대신 지금 인기 있는 상품을 보여 드릴게요."를 보여 주고, 인기 상품 카드를 대신 보여 줍니다. 이때는 [더 보기]가 없습니다.

> 지금 데이터에는 모든 카테고리에 상품이 있어서 이 안내는 보이지 않습니다. 관리자가 한 카테고리의 상품을 모두 판매 중지하면 확인할 수 있습니다.

### 검색 (UC-05 1~2단계)

- 검색창에 입력하고 **[검색]**을 누르거나 **Enter**를 누르면 검색합니다.
- 빈칸으로 검색하면 검색창 왼쪽에 빨간 "검색어를 입력해 주세요"가 뜨고 칸 테두리가 빨갛게 됩니다. 보던 목록은 그대로입니다.
- **모든 카테고리**에서 상품명·브랜드·카테고리 이름(세부 카테고리 포함)으로 찾습니다 (FR-06, `ProductService.search`). 예: "하의"로 검색하면 하의 전체가 나옵니다.
- 홈 화면의 검색창이나 카테고리 버튼을 누르면 `openSearch(검색어)`·`openCategory(카테고리)`로 이 화면이 열립니다.
- 검색 중에는 카테고리 버튼이 아무것도 선택되지 않은 상태가 됩니다. 검색 결과는 한 번에 모두 보여 주고 [더 보기]는 없습니다.
- **[검색 지우기]**를 누르면 검색 전에 보던 카테고리로 돌아갑니다. 카테고리 버튼을 눌러도 검색이 끝납니다.
- 새 검색어로 검색하면 필터와 정렬은 처음 상태로 돌아갑니다.

**결과가 없을 때 (2a)**: "'○○'에 맞는 상품이 없어요" 아래에 **자주 찾는 검색어** 버튼(가디건, 니트, 블라우스, 슬랙스, 스커트)과 "지금 인기 있는 상품"을 보여 줍니다. 검색어 버튼을 누르면 그 단어로 바로 검색합니다.

> 처음 만들 때는 명세의 "비슷한 검색어"를 만들어 주는 Controller 기능이 없어서, 화면에 정해 둔 자주 찾는 검색어로 대신했습니다. 지금은 `ProductController.suggestKeywords(keyword)`가 생겼지만 화면은 아직 이것을 부르지 않고 고정 검색어를 씁니다.

### 필터와 정렬 (UC-05 3~4단계)

필터와 정렬은 **검색 결과에서만** 보입니다. 명세의 `SearchFilter`에 카테고리 조건이 없어서, 카테고리 목록을 필터로 좁히는 방법이 없기 때문입니다.

| 줄 | 내용 |
|---|---|
| 첫째 줄 | [연령대 전체 ▼] [체형 전체 ▼] [사이즈 전체 ▼] |
| 둘째 줄 | [가격대 전체 ▼] [색상 전체 ▼] [내 체형에 맞는 상품] 필터 초기화 |
| 셋째 줄 | 정렬: [인기순] [신상품순] [낮은 가격순] [높은 가격순]. 처음은 인기순 |

- 선택 상자의 첫 항목("연령대 전체" 등)이 이름 역할을 하고, "전체"는 조건 없음입니다.
- 필터나 정렬을 바꾸면 **[적용] 버튼 없이 바로** 목록과 결과 개수가 바뀝니다.
- **[필터 초기화]**: 모든 필터를 "전체"로, 정렬을 인기순으로 되돌립니다.
- 필터 때문에 결과가 없으면 "'가디건' 중 조건에 맞는 상품이 없어요"와 "필터를 줄이거나 [필터 초기화]를 눌러 보세요"를 보여 줍니다.
- 결과가 적어도 스크롤바 자리를 비워 두어 화면이 좌우로 흔들리지 않습니다.

**[내 체형에 맞는 상품] (3a)**: 로그인했고 내 정보에 연령대·체형·사이즈 중 하나라도 있는 회원에게만 보입니다. 누르면 그 값으로 세 필터를 한 번에 채우고 바로 목록을 바꿉니다. 그래서 필터의 연령대·체형·사이즈 선택지는 회원가입과 **같은 목록**을 씁니다.

| 필터 | 선택지 (임시) | `SearchFilter`에 넘기는 값 |
|---|---|---|
| 연령대 | 40대, 50대, 60대 | `ageGroup` (예: `"50대"`) |
| 체형 | 마른, 보통, 통통한, 하체 발달형, 상체 발달형 | `bodyType` (예: `"보통 체형"`) |
| 사이즈 | S (55) ~ XXL (99) | `size` (예: `"M (66)"`) |
| 가격대 | 10만원 이하, 10~30만원, 30~50만원, 50만원 이상 | `minPrice`·`maxPrice` (원, 둘 다 포함). 예: 10~30만원 → 100001 ~ 300000 |
| 색상 | 블랙, 화이트·아이보리, 네이비, 그레이, 베이지·브라운 | `color` (예: `"네이비"`) |
| 정렬 | 인기순, 신상품순, 낮은 가격순, 높은 가격순 | `sort`: `POPULAR`, `NEWEST`, `PRICE_LOW`, `PRICE_HIGH` |

### 상품 상세 (UC-06)

목록의 카드를 누르면 `frame.openProduct(상품 번호)`로 열립니다. 맨 위 **[← 상품 목록으로]**를 누르면 보던 목록(카테고리나 검색 결과)으로 돌아갑니다.

| 영역 | 내용 |
|---|---|
| 왼쪽 | 큰 사진 (전체가 보이게, 3:4 칸). 아래에 "사진을 누르면 크게 볼 수 있어요". 사진이 여러 장이면 번호 버튼으로 바꿔 볼 수 있음 |
| 가운데 | 얇은 세로 구분선 |
| 오른쪽 | 큰 가격 → 상품명 → "★ 4.7 리뷰 3개"(누르면 리뷰로 내려감) → 소재 → 사이즈 → 색상 → 수량 → [AI로 입어보기] |
| 아래 고정 줄 | 화면을 내려도 늘 보이는 구매 줄: [♡ 찜] · 합계 금액 ········ [장바구니 담기] [바로 구매]. 오류 문장은 버튼 바로 위에 나옵니다 |
| 아래 | 사이즈표, 리뷰 |

창이 좁거나 글씨가 크면 사진이 위, 정보가 아래로 바뀝니다.

**사진 크게 보기 (3단계)**: 큰 사진이나 리뷰 사진을 누르면 창 크기의 85%로 "사진 크게 보기" 창이 열립니다. **[닫기]**나 **Esc**로 닫고, 사진이 여러 장이면 [이전 사진] [다음 사진]으로 넘깁니다.

**사이즈·색상 (4단계, 4b)**
- 알약 모양 선택 버튼입니다(`Theme.outlineChip`). 고르지 않은 것은 흰 바탕에 테두리입니다. 고른 사이즈는 검정이고, 고른 **색상은 그 색**(베이지, 네이비 등)으로 채워집니다. 색은 이름에서 가장 앞의 색 낱말로 정하고("차콜 블랙" → 차콜), 모르는 이름("기본" 등)은 검정입니다. 화이트처럼 밝은 색은 진한 테두리로 고른 것을 표시합니다.
- **품절**은 "XL (88) 품절"처럼 글자가 붙고, 흰 바탕에 회색 글씨로 바뀌어 누를 수 없습니다. 사이즈는 모든 색이 품절일 때, 색상은 고른 사이즈에서 품절일 때 막힙니다. 고른 색이 새 사이즈에서 품절이면 색 선택이 풀립니다.
- 색이 한 가지뿐이면 미리 골라 둡니다.
- 고르지 않고 버튼을 누르면 "사이즈를 골라 주세요" / "색상을 골라 주세요"가 이름표 옆에 뜨고, 고를 버튼으로 커서가 갑니다.

**수량**: 색상 아래 `[−] N개 [+]   합계 ○○원`. 1개보다 줄지 않고, 고른 사이즈·색상의 재고까지만 늘어납니다(넘으면 "최대 10개까지 살 수 있어요"). 다른 상품을 열면 1개로 돌아갑니다.

**버튼 (4단계, 4a)**: [바로 구매]·[장바구니 담기]는 고른 수량을 넘깁니다. 비회원이 [바로 구매]·[장바구니 담기]·[찜하기]를 누르면 **로그인 화면**으로 가고, 로그인하면 이 화면으로 돌아옵니다. 고른 사이즈·색상도 그대로 남아 있습니다.

| 버튼 | 부르는 것 | 결과 |
|---|---|---|
| [바로 구매] | `context.order.prepareDirect(OrderLine)` | 이 상품 하나로 주문서를 만들고 `frame.openOrder(sheet)`로 주문서 화면을 엽니다 ([docs/order-view.md](order-view.md)) |
| [장바구니 담기] | `context.cart.add(OrderLine)` | 화면을 막지 않는 알림(`Toast`) "장바구니에 담았어요 · [장바구니 보기]"가 5초 동안 뜨고, 상단 메뉴가 "장바구니 n"으로 바뀝니다. 같은 옵션이 이미 있으면 수량을 더합니다 ([docs/order-view.md](order-view.md)) |
| [AI로 입어보기] | `TryOnPanel.wear(상품 번호)` | 옷 입혀보기 화면의 맞는 칸(모자·상의·하의·주얼리·신발)에 담아 두기만 함(입혀 보는 것은 거기서 [입혀보기]를 눌렀을 때). 원피스·아우터·양말·가방·스카프는 "아직 입어 볼 수 없어요" 안내. 사이즈·색상은 고르지 않아도 됨 |

| [♡ 찜] (UC-10 1a) | `context.cart.toggleWish(상품 번호)` | 찜하면 버튼이 "♥ 찜"으로 바뀌고 "찜했어요 · [찜 목록 보기]" 알림이 뜹니다. 다시 누르면 해제됩니다. 찜 여부는 `context.cart.isWished(상품 번호)`로 확인(비회원이면 늘 찜 안 함). 찜한 상품은 장바구니 화면 아래에 모여 보입니다 |

`AppException`(예: 그사이 품절)이 오면 아래 고정 줄의 버튼 바로 위에 빨간 글씨로 그대로 보여 줍니다. 사이즈·색상을 고르지 않고 누르면 "사이즈를 먼저 골라 주세요"를 보여 주고 고를 곳으로 화면을 올립니다.

**사이즈표**: `Product`에 치수 정보가 없어서 **모든 상품에 공통인 사담다 표준 치수**(S(55)~XXL(99)의 가슴·허리·엉덩이 둘레, cm)를 보여 주고 "상품마다 조금 다를 수 있어요"라고 안내합니다.

**리뷰 (FR-23 조회)**: `context.product.reviews(상품 번호)`로 리뷰 쓰기(UC-14, [docs/review.md](review.md))에서 쓴 리뷰를 보여 줍니다. 예전 목업에 있던 데모 리뷰는 통합 때 사라졌습니다. "리뷰 3개 ★ 4.7" 아래에 별점(★★★★☆ 4점), 쓴 사람의 체형 정보("50대 · 160cm · M (66) · 보통 체형"), 내용, 리뷰 사진을 보여 줍니다. 리뷰가 없으면 "아직 리뷰가 없어요."

## 5. 다른 화면에서 쓸 수 있는 부품

> **화면을 만드는 분(김대원 님: 관리자 화면)만 읽으시면 됩니다.**

### `ProductImages`: 상품 사진 불러오기

상품 상세, 장바구니, 관리자 상품 관리처럼 상품 사진이 나오는 화면에서 같이 씁니다.

```java
ProductImages.request(url, this::repaint);   // 불러오기 시작. 끝나면(성공·실패 모두) repaint
BufferedImage image = ProductImages.get(url); // 아직 없으면 null
boolean noPhoto = ProductImages.failed(url);  // 받을 수 없으면 true
```

- 주소가 `http://`·`https://`로 시작하면 인터넷에서, 아니면 **PC의 파일 경로**로 보고 읽습니다. 관리자가 사진 파일로 상품을 등록해도(UC-16) 같은 방법으로 보입니다.
- 화면을 멈추지 않고 따로 불러옵니다. 같은 사진은 한 번만 받아서 저장해 두고 다시 씁니다.
- 폭 720px보다 큰 사진은 줄여서 저장합니다 (메모리 절약).
- JPG·PNG·GIF를 읽을 수 있습니다. WebP 등 다른 형식은 "사진 없음"이 됩니다.

### `frame.openProduct(상품 번호)`: 상품 상세 열기

룩북(UC-07)·홈 추천(UC-08)처럼 상품을 보여 주는 화면에서 상품을 누르면 이것만 부르면 됩니다. 상세 화면이 그 상품을 불러와 보여 줍니다.

### `Theme.chip(문구)`: 여러 개 중 하나 고르는 버튼

```java
ButtonGroup group = new ButtonGroup();          // 하나만 선택되게 묶는다
JToggleButton chip = Theme.chip("상의");
chip.addActionListener(e -> showCategory(...));
group.add(chip);
```

고른 것은 검정 바탕에 흰 글씨, 나머지는 연한 회색 바탕입니다. `setEnabled(false)`면 흰 바탕·테두리·회색 글씨로 바뀌어 누를 수 없습니다(품절 등). 높이 48px 이상이고 [글씨 크기]를 따라 커집니다. 상품 카테고리, 검색 결과의 정렬 버튼에 쓰고 있습니다.

고르지 않았을 때 흰 바탕에 테두리만 있는 칩은 `Theme.outlineChip(문구)`, 고르면 정한 색으로 채우는 칩은 `Theme.outlineChip(문구, 색)`입니다. 상세 화면의 사이즈·색상 버튼에 씁니다.

버튼이 여러 개라 한 줄에 다 안 들어갈 수 있으면 `new JPanel(new WrapLayout(FlowLayout.LEFT, 12, 8))`에 담으면 다음 줄로 넘어갑니다.

## 7. 팀에서 함께 정할 것

| 항목 | 지금 값 / 상황 |
|---|---|
| 한 페이지 상품 수 | 8개 (`ProductService.PAGE_SIZE`) |

| 자주 찾는 검색어 | 가디건, 니트, 블라우스, 슬랙스, 스커트 (임시, 화면에 고정) |

| 원피스·아우터·가방·스카프 데이터 | 각 5개뿐 (다른 카테고리는 35~105개) |
