# View 작업 안내: 상품 목록·검색 화면

작성: 강준서 (View 담당) · 2026-11-14 · 브랜치 `feat/product-view`

상품 목록(UC-04 카테고리별 상품 조회)과 검색(UC-05 상품 검색 및 필터) 화면을 만들었습니다. 큰 카테고리 버튼을 누르면 해당 상품을 큰 사진 카드로 보여 주고, [더 보기]로 이어서 볼 수 있습니다. 검색하면 모든 카테고리에서 찾고, 검색 결과는 필터와 정렬로 좁힐 수 있습니다. 아직 `Product`에 getter가 없어서 **목업 데이터로 동작**합니다 (4번 참고).

공통 디자인(`Theme`)과 화면 이동 규칙은 [docs/auth-view.md](auth-view.md)를 참고해 주세요.

---

## 1. 바로 보기

1. IDE에서 `com.sadamda.App`의 `main`을 실행합니다.
2. 상단 메뉴 **[상품]**을 누릅니다. 로그인하지 않아도 볼 수 있습니다.

> 상품 사진은 쇼핑몰 이미지 주소에서 받아 옵니다. **인터넷이 연결되어 있어야** 사진이 보입니다. 연결이 없으면 사진 칸에 "사진 없음"이 나오고, 나머지는 정상으로 동작합니다.

화면 구성 (위에서 아래로):

| 영역 | 내용 |
|---|---|
| 머리말 | 왼쪽에 "상품" 제목, 오른쪽에 **검색창과 [검색]** 버튼. 그 아래 카테고리 버튼 **[상의] [하의] [원피스] [아우터]**. 고른 버튼은 검정, 나머지는 연한 회색. 목록을 내려도 그대로 보임 |
| 검색 결과 안내 (검색했을 때만) | "'가디건' 검색 결과 7개"와 [검색 지우기], 필터 두 줄과 정렬 버튼 한 줄 |
| 상품 카드 | 연한 회색 칸에 사진, 그 아래 상품명(두 줄까지), 굵은 가격 |
| 맨 아래 | **[더 보기]** 버튼 (더 볼 상품이 있을 때만) |

## 3. 화면이 동작하는 방식

### 카테고리 (UC-04 1~2단계)

- 처음 열면 **상의**를 보여 줍니다. 다른 화면에 다녀와도 보던 카테고리와 스크롤 위치를 유지합니다.
- 카테고리 버튼을 누르면 그 카테고리의 첫 페이지를 보여 주고 맨 위로 올라갑니다.

### 상품 카드

- 사진은 칸에 꽉 차게 넣고 넘치는 부분은 잘라냅니다. 칸 비율은 쇼핑몰 사진에 맞춘 3:4입니다.
- 상품명은 두 줄까지 보이고, 넘치면 "…"로 줄입니다. 마우스를 올리면 전체 이름이 보입니다.
- 상품명이 한 줄이어도 두 줄 자리를 잡아서, 같은 줄의 가격 위치가 가지런합니다.
- **카드 전체가 버튼**입니다. 마우스로 누르거나, Tab으로 이동해 Space를 누르면 상품 상세(UC-06)로 갑니다. 키보드로 오면 사진 둘레에 검정 테두리가 보입니다.
- 지금은 상세 화면이 TODO라서 **화면 이동만** 합니다. 상세 화면을 만들 때 상품 번호를 넘기도록 바꿀 예정입니다.

### 한 줄에 놓이는 카드 수

카드 폭은 항상 **240px 이상**입니다 (NFR-02 목록 이미지 너비). 창 폭에 맞춰 한 줄의 카드 수가 자동으로 바뀝니다.

| 상황 | 한 줄 카드 수 |
|---|---|
| 창 폭 1280px, 글씨 보통 | 4개 |
| 창 폭 1280px, 글씨 아주 크게 | 3개 (글씨가 커지면 최소 폭도 커짐) |
| 창 폭 800px, 글씨 보통 | 2개 |

### [더 보기] (UC-04 3단계)

- 한 번에 **8개**씩 보여 주고, [더 보기]를 누르면 다음 8개를 아래에 덧붙입니다 (`page`가 0부터 1씩 늘어남).
- 받아 온 상품이 8개보다 적으면 마지막 페이지로 보고 버튼을 감춥니다.
- 누른 뒤에는 키보드 포커스가 **새로 붙은 첫 상품**으로 옮겨 갑니다.

### 상품이 없을 때 (UC-04 2a)

"**준비 중인 상품입니다**"와 "대신 지금 인기 있는 상품을 보여 드릴게요."를 보여 주고, 인기 상품 카드를 대신 보여 줍니다. 이때는 [더 보기]가 없습니다.

> 목업에는 원피스·아우터 상품이 일부러 없습니다. 두 버튼을 누르면 이 흐름을 확인할 수 있습니다.

### 검색 (UC-05 1~2단계)

- 검색창에 입력하고 **[검색]**을 누르거나 **Enter**를 누르면 검색합니다.
- 빈칸으로 검색하면 검색창 왼쪽에 빨간 "검색어를 입력해 주세요"가 뜨고 칸 테두리가 빨갛게 됩니다. 보던 목록은 그대로입니다.
- **모든 카테고리**에서 상품명과 카테고리 이름으로 찾습니다 (FR-06). 예: "하의"로 검색하면 하의 전체가 나옵니다.
- 검색 중에는 카테고리 버튼이 아무것도 선택되지 않은 상태가 됩니다. 검색 결과는 한 번에 모두 보여 주고 [더 보기]는 없습니다.
- **[검색 지우기]**를 누르면 검색 전에 보던 카테고리로 돌아갑니다. 카테고리 버튼을 눌러도 검색이 끝납니다.
- 새 검색어로 검색하면 필터와 정렬은 처음 상태로 돌아갑니다.

**결과가 없을 때 (2a)**: "'○○'에 맞는 상품이 없어요" 아래에 **자주 찾는 검색어** 버튼(가디건, 니트, 블라우스, 슬랙스, 스커트)과 "지금 인기 있는 상품"을 보여 줍니다. 검색어 버튼을 누르면 그 단어로 바로 검색합니다.

> 명세의 "비슷한 검색어"를 만들어 주는 Controller 기능이 없어서, 화면에 정해 둔 자주 찾는 검색어로 대신했습니다.

### 필터와 정렬 (UC-05 3~4단계)

필터와 정렬은 **검색 결과에서만** 보입니다. 명세의 `SearchFilter`에 카테고리 조건이 없어서, 카테고리 목록을 필터로 좁히는 방법이 없기 때문입니다.

| 줄 | 내용 |
|---|---|
| 첫째 줄 | [연령대 전체 ▼] [체형 전체 ▼] [사이즈 전체 ▼] |
| 둘째 줄 | [가격대 전체 ▼] [색상 전체 ▼] [내 체형에 맞는 상품] 필터 초기화 |
| 셋째 줄 | 정렬: [인기순] [신상품순] [낮은 가격순] [높은 가격순]. 처음은 인기순 |

- 선택 상자의 첫 항목("연령대 전체" 등)이 이름 역할을 하고, "전체"는 조건 없음입니다.
- 필터나 정렬을 바꾸면 **[적용] 버튼 없이 바로** 목록과 결과 개수가 바뀝니다.
- **[필터 초기화]**: 모든 필터를 "전체"로, 정렬을 인기순으로 되돌립니다.
- 필터 때문에 결과가 없으면 "'가디건' 중 조건에 맞는 상품이 없어요"와 "필터를 줄이거나 [필터 초기화]를 눌러 보세요"를 보여 줍니다.
- 결과가 적어도 스크롤바 자리를 비워 두어 화면이 좌우로 흔들리지 않습니다.

**[내 체형에 맞는 상품] (3a)**: 로그인했고 내 정보에 연령대·체형·사이즈 중 하나라도 있는 회원에게만 보입니다. 누르면 그 값으로 세 필터를 한 번에 채우고 바로 목록을 바꿉니다. 그래서 필터의 연령대·체형·사이즈 선택지는 회원가입과 **같은 목록**을 씁니다.

| 필터 | 선택지 (임시) | `SearchFilter`에 넘기는 값 |
|---|---|---|
| 연령대 | 40대, 50대, 60대 | `ageGroup` (예: `"50대"`) |
| 체형 | 마른, 보통, 통통한, 하체 발달형, 상체 발달형 | `bodyType` (예: `"보통 체형"`) |
| 사이즈 | S (55) ~ XXL (99) | `size` (예: `"M (66)"`) |
| 가격대 | 10만원 이하, 10~30만원, 30~50만원, 50만원 이상 | `minPrice`·`maxPrice` (원, 둘 다 포함). 예: 10~30만원 → 100001 ~ 300000 |
| 색상 | 블랙, 화이트·아이보리, 네이비, 그레이, 베이지·브라운 | `color` (예: `"네이비"`) |
| 정렬 | 인기순, 신상품순, 낮은 가격순, 높은 가격순 | `sort`: `POPULAR`, `NEWEST`, `PRICE_LOW`, `PRICE_HIGH` |

### 이번에 넣지 않은 것

레퍼런스(쇼핑몰 화면)에 있었지만 명세 범위가 달라서 뺐습니다.

| 기능 | 이유 |
|---|---|
| 순위 번호 | 명세에 없음 (인기순 정렬로 대신) |
| 할인율 | `Product`에 할인 정보가 없음 |
| 거래 수 | 명세에 없음 |
| 관심(북마크) 표시 | UC-10 범위 |
| 카테고리 목록에서 필터 | `SearchFilter`에 카테고리 조건이 없음 |

## 4. 목업 데이터와 교체 방법

`MockProducts`는 상의 10개, 하의 10개를 가지고 있습니다. 상품명과 가격은 팀 데모 데이터(`products.tsv`)를 참고해 정리했고, 사진은 그 데이터의 쇼핑몰 이미지 주소를 그대로 씁니다. 필터·정렬을 확인하려고 상품마다 연령대, 체형, 사이즈, 색상, 판매 수, 등록 순서를 **임의로** 붙였습니다.

`Product`에 getter가 생기면 아래 순서로 바꿉니다. **화면 코드는 세 메서드만 고치면 됩니다.**

1. `ProductListPanel`의 `fetch(...)`를 `context.product.listByCategory(category, page)`로 바꾸고, 결과 `Product`를 `ProductItem`으로 옮겨 담습니다.
2. `fetchPopular()`를 `context.product.popular()`로 같은 방식으로 바꿉니다.
3. `fetchSearch(filter)`를 `context.product.search(filter)`로 바꿉니다. 화면은 이미 명세의 `SearchFilter`를 만들어 넘기고 있습니다.
4. `MockProducts.java`를 지웁니다. 한 페이지 상품 수(지금 8개)는 Model의 페이지 크기에 맞춥니다.

| `ProductItem` | 가져올 곳 |
|---|---|
| `id` | `Product`의 id |
| `name` | 상품명 |
| `price` | 가격 |
| `imageUrl` | `imageUrls`의 첫 번째 (대표 사진). 없으면 `null` → 화면에 "사진 없음" |

## 5. 다른 화면에서 쓸 수 있는 부품

> **화면을 만드는 분(김대원 님: 관리자 화면)만 읽으시면 됩니다.**

### `ProductImages`: 상품 사진 불러오기

상품 상세, 장바구니, 관리자 상품 관리처럼 상품 사진이 나오는 화면에서 같이 씁니다.

```java
ProductImages.request(url, this::repaint);   // 불러오기 시작. 끝나면(성공·실패 모두) repaint
BufferedImage image = ProductImages.get(url); // 아직 없으면 null
boolean noPhoto = ProductImages.failed(url);  // 받을 수 없으면 true
```

- 주소가 `http://`·`https://`로 시작하면 인터넷에서, 아니면 **PC의 파일 경로**로 보고 읽습니다. 관리자가 사진 파일로 상품을 등록해도(UC-16) 같은 방법으로 보입니다.
- 화면을 멈추지 않고 따로 불러옵니다. 같은 사진은 한 번만 받아서 저장해 두고 다시 씁니다.
- 폭 720px보다 큰 사진은 줄여서 저장합니다 (메모리 절약).
- JPG·PNG·GIF를 읽을 수 있습니다. WebP 등 다른 형식은 "사진 없음"이 됩니다.

### `Theme.chip(문구)`: 여러 개 중 하나 고르는 버튼

```java
ButtonGroup group = new ButtonGroup();          // 하나만 선택되게 묶는다
JToggleButton chip = Theme.chip("상의");
chip.addActionListener(e -> showCategory(...));
group.add(chip);
```

고른 것은 검정 바탕에 흰 글씨, 나머지는 연한 회색 바탕입니다. 높이 48px 이상이고 [글씨 크기]를 따라 커집니다. 상품 카테고리와 검색 결과의 정렬 버튼에 쓰고 있습니다.

## 6. 담당자께 부탁드릴 일

### 정우진 님 (상품)

- **`Product` getter**가 있어야 목업을 실제 데이터로 바꿀 수 있습니다. 목록 화면에는 id, 상품명, 가격, 사진 목록(`imageUrls`)이 필요합니다.
- `findByCategory(category, page)`의 **한 페이지 상품 수**를 알려 주세요. 화면은 "받은 수가 한 페이지보다 적으면 마지막"으로 판단합니다.
- `imageUrls`에는 쇼핑몰 주소(`https://...`)나 PC 파일 경로 둘 다 넣을 수 있습니다.
- **`search(SearchFilter)` 값의 뜻**을 3번 "필터와 정렬" 표처럼 맞춰 주세요. 특히:
  - 연령대·체형·사이즈는 회원가입과 같은 문자열입니다 (예: `"M (66)"`). 상품의 추천 연령대·체형 태그와 옵션 사이즈도 같은 값이면 바로 맞습니다.
  - 색상은 "화이트·아이보리"처럼 **비슷한 색을 묶은 이름**입니다. 상품 옵션의 색 이름과 어떻게 맞출지 정해야 합니다.
  - 가격은 `minPrice`·`maxPrice` 둘 다 포함, 정렬은 `POPULAR`·`NEWEST`·`PRICE_LOW`·`PRICE_HIGH`로 보냅니다.

### 김대원 님 (Controller)

- 명세의 `listByCategory(category, page)`, `popular()`, `search(filter)` 그대로 연결할 예정입니다.
- `SearchFilter`에 카테고리 조건이 없어서 필터는 검색 결과에서만 보이게 했습니다. 카테고리 목록에서도 필터를 쓰려면 `SearchFilter`에 카테고리를 추가해 주셔야 합니다 (지금은 필요 없음).
