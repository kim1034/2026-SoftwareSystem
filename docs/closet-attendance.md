# 옷장 출석 (UC-21)

담당: 정우진 · 브랜치 `feat/closet-attendance` (`feat/codi-book` 위에 쌓음)

흔한 출석체크는 도장만 찍고 바로 나가서 체류시간이 몇 초에 그친다. 옷장 출석은 출석하면 **그날의 코디**를 주고,
그 코디를 바로 캐릭터에 입혀 보게 해서 출석이 곧 옷 입혀보기의 입구가 되게 했다.

## 규칙
- 하루 한 번 출석. 같은 날 다시 눌러도 한 칸이다.
- **연속 출석이 아니라 "이번 주 7칸 중 몇 칸"으로 센다.** 하루 빠져도 그 주가 끝나지 않아 중장년 사용자가 부담 없이 이어 간다.
- 한 주(월~일)에 **5칸**을 채우면 **무료배송 쿠폰 1장**을 준다. 쿠폰은 한 주에 한 번만 준다.
- 쿠폰은 주문서에서 쓰며, 쓰면 배송비 3,000원이 0원이 된다.
- 그날의 코디는 상황별 코디 도우미(UC-20)로 고른다. 날짜마다 상황이 돌아가고(결혼식 → 모임 → 여행 → 일상), 요일마다 순위의 다른 자리를 골라 일주일 동안 같은 상의가 나오지 않는다. 날짜·체형이 같으면 늘 같은 코디라서 따로 저장하지 않는다.

## UC-21 옷장 출석

| 항목 | 내용 |
|---|---|
| Actor | 회원 |
| 사전조건 | 로그인 상태다 |
| 사후조건 | 오늘 칸에 도장이 찍히고 그날의 코디가 보인다. 이번 주 5칸을 처음 채웠으면 무료배송 쿠폰 1장이 생긴다 |

**기본 흐름**
1. 회원이 홈 화면의 "옷장 출석"에서 이번 주 7칸(월~일)과 가진 쿠폰 수를 본다.
2. 회원이 [오늘 출석하고 코디 받기]를 누른다.
3. 시스템이 오늘 칸에 도장을 찍고, 회원 체형·연령대에 맞춘 오늘의 코디를 보여준다.
4. 이번 주 5칸을 처음 채웠으면 시스템이 무료배송 쿠폰 1장을 주고 알린다.
5. 회원이 [캐릭터에 입혀보기]를 누르면 옷 입혀보기 화면에서 그 코디를 입혀 본다. [코디북에 저장](UC-19)도 할 수 있다.

**대안 흐름**
- 1a. 비회원에게는 로그인 안내와 [로그인하기]만 보여준다.
- 2a. 오늘 이미 출석했으면 버튼이 [오늘의 코디 다시 보기]로 바뀐다.
- 5a. 출석한 날 칸을 누르면 그날의 코디를 다시 본다. 쉰 날은 볼 수 없다.

**UC-11 확장 (주문서)**
- 가진 쿠폰이 있으면 주문서에 "쿠폰" 칸이 생긴다. [무료배송 쿠폰 쓰기]를 고르면 배송비와 결제 금액이 바로 바뀐다.
- 결제가 끝난 뒤에 쿠폰 1장을 쓴다. 결제가 실패하면 쿠폰은 그대로 남는다.
- 쿠폰이 없는데 쿠폰 결제를 요청하면 결제하지 않고 안내한다.

**구현**: `HomePanel`(`AttendanceRow`, `AttendanceDialog`) → `AttendanceController` → `AttendanceService`, `OutfitHelper.dailyOutfit`
주문: `OrderPanel` → `OrderController.checkout`(`CheckoutRequest.freeShippingCoupon`) → `OrderService.placeOrder(…, freeShipping)`

**저장 위치**: `사용자 홈/.sadamda/attendance/{회원 열쇠}.properties` (회원 열쇠는 `common/OwnerKeys`, 코디북과 같은 방식)

## 다른 담당자 코드에 손댄 곳
- `OrderService`: `calculateTotal(lines, freeShipping)`, `placeOrder(…, freeShipping)`를 **더했다**. 예전 메서드는 그대로 두고 새 메서드를 부른다.
- `OrderController`: 쿠폰 지갑(`AttendanceService`)을 받는 생성자를 더했다. 쿠폰을 쓰지 않으면 예전과 같은 메서드를 불러서 기존 JUnit(Mockito) 테스트의 호출 검증이 그대로 맞는다.
- `CheckoutRequest`: `freeShippingCoupon` 칸을 더하고, 예전 5개짜리 생성자를 남겼다.
- `OrderPanel`: 쿠폰 칸과 최종 주문정보 다시 그리기.

## 확인
`DomainSelfCheck`에 UC-21 검사 20개를 더했다(전체 216개 통과). 내용: 주 단위 세기, 쿠폰 1회, 다시 켜도 유지, 날마다 다른 코디, 쿠폰 결제 시 배송비 0원과 쿠폰 차감.
화면은 홈 출석 칸, 오늘의 코디 창, 주문서 쿠폰 칸을 실제로 그려 확인했다.
